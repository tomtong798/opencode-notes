# effect/cli

## 是什么

Effect 官族的命令行框架：声明式定义命令树（`Command.make`）、选项（`Options`）、参数（`Args`），获得类型化解析、自动 help、组合式处理器。

## 业界类比

- Commander.js / clipanion / oclif 的 Effect 系对应物
- "命令也是效应"——handler 返回 Effect，天然复用 DI/错误通道/并发

## 在 OpenCode 中的角色

- **`opencode` 命令的全部解析层**（`packages/cli`）：
  - 命令树：默认=TUI、`serve`、`run`（非交互）、`mini`、`service`、`auth`、`mcp`、`plugin`、`session`、`models`、`stats`、`acp`、`pair`、`upgrade`…
  - handler 懒加载：`Runtime.handlers()` 注册，避免启动敏感路径加载重模块
  - 入口还处理：SSH askpass 捷径、heap/CPU profiling、未捕获异常、OTEL 观测

## 与其他技术的关系

- **Effect**：同族骨架（见 [effect.md](3_effect.md)）
- **Bun**：入口是 Bun 脚本（`#!/usr/bin/env bun`），`packages/cli/src/index.ts`
- **TUI**：默认命令的 handler 调 `@opencode/tui` 的 `run()`

## 相关源码

- `packages/cli/src/index.ts`（入口）、`commands/commands.ts`（命令树）、`framework/runtime.ts`（懒加载框架）、`commands/handlers/*`
