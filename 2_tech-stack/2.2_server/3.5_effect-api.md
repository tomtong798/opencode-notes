# Effect-TS 核心 API 速查（opencode 实用版）

> 面向：要读/写 opencode 代码时的快速查阅。
> 组织：按 opencode 实际 import 的模块分节，每节「常用 API 表 + Go 对照 + 现码出处」。
> 版本：effect **4.0.1**（v2.0.30 / dev 分支实测）；统计为 core/src grep 计数。
> 姊妹篇：概念与学习路径见 [3.4_effect-guide.md](3.4_effect-guide.md)。

## 模块总览（opencode 实际使用的 10 个模块）

| 模块 | 一句话 | Go 类比 | 使用热度 |
|---|---|---|---|
| `Effect` | 计算核心类型 `Effect<A,E,R>` | `func(ctx) (A, error)` 的值化 | ★★★★★ |
| `Schema` | 建模+校验二合一（effect 的） | struct + validator 合一 | ★★★★★（1,700 处） |
| `Context` | 服务标识（DI 的 tag） | 接口 + 唯一 key | ★★★★（151 个 Service） |
| `Layer` | 服务的"构造函数" | 构造函数/依赖组装 | ★★★★（142 处） |
| `Stream` | 流式数据（LLM 输出载体） | 带背压的 chan | ★★★（196 处） |
| `Scope` | 资源生命周期 | 可组合的 defer 域 | ★★★ |
| `Fiber` | 可取消并发单元 | 可取消的 goroutine | ★★（经 fork 间接使用） |
| `PubSub`/`Queue` | 进程内消息通道 | channel | ★★ |
| `Ref` | 并发安全的可变引用 | `atomic.Value` | ★★ |
| `Duration` | 时长类型 | `time.Duration` | ★ |

> 另有 opencode **自建**的 `LayerNode`/`LayerMap`（`packages/util/src/effect/`、`core/src/location-*.ts`），不是 Effect 标准库——见文末专节。

## 1. `Effect` —— 构造

| API | 作用 | Go 对照 |
|---|---|---|
| `Effect.succeed(x)` | 立即成功 | `return x, nil` |
| `Effect.fail(err)` / `yield* new Err({})` | 类型化失败（后者更常用） | `return nil, err` |
| `Effect.sync(() => x)` | 包装同步计算 | 普通函数体 |
| `Effect.tryPromise(fn)` | 包装 Promise（失败转 defect 或映射） | `await` |
| `Effect.gen(function*(){})` | 顺序串联（**主流**，539 处） | 顺序函数体 |
| `Effect.fn("名")(fn)` | 命名 gen（追踪/日志，745 处） | 函数名 |
| `Effect.die(x)` | 致命缺陷（不可恢复） | panic |
| `Effect.void` | 什么都不做的成功 | `return nil, nil` |

## 2. `Effect` —— 组合与变换

| API | 作用 | Go 对照 |
|---|---|---|
| `eff.pipe(Effect.map(f))` | 变换成功值 | `f(v)` |
| `eff.pipe(Effect.flatMap(f))` | 串联下一个 Effect | 顺序调用 |
| `eff.pipe(Effect.tap(f))` | 副作用不改值 | 打日志后返回 |
| `Effect.all([...])` / `Effect.all({...})` | 并发执行收集结果（23 处） | goroutine + WaitGroup |
| `Effect.forEach(xs, f, { discard, concurrency })` | 遍历（discard 只副作用不收集，13 处） | `for` + 可选并发 |
| `Effect.as(x)` / `Effect.asVoid` | 替换/丢弃成功值 | `return x, nil`（换值） |
| `Effect.context()` | 取当前依赖环境（动态用服务的入口） | 读 ctx |
| `Effect.uninterruptibleMask` | 中断保护区内恢复中断（工具执行用它） | 临界区 |

## 3. `Effect` —— 错误处理

| API | 作用 | Go 对照 | 热度 |
|---|---|---|---|
| `Schema.TaggedError<T>()("标签", {...})` | 定义带字段错误类 | 自定义 error struct | 108 处 |
| `Effect.catchTag("标签", h)` | 按标签捕获，其余传播 | `errors.As` + 类型安全 handler | 45 处 |
| `Effect.catchTags({...})` | 多标签批量处理 | 多路 errors.As | 3 处 |
| `Effect.catchAll(h)` | 兜底全捕 | `if err != nil` | 少用（会吞类型） |
| `Effect.orDie` | 可恢复错误 → 缺陷（panic 语义） | `panic(err)` | 50+ 处 |
| `Effect.retry(policy)` | 按策略重试 | 手写退避循环 | provider 调用处 |
| `Effect.ensuring(cleanup)` | 无论成败执行收尾 | `defer` | 流式收尾常用 |

## 4. `Effect` —— 执行入口（惰性 → 触发）

| API | 作用 | Go 对照 | 热度 |
|---|---|---|---|
| `Effect.runFork(eff)` | 后台执行返回 Fiber | `go func()` | 23 处 |
| `Effect.runForkWith(context)(eff)` | 带依赖环境后台执行 | 带闭包环境的 go | 5 处（pty/shell/mcp） |
| `Effect.runPromise(eff)` | 执行为 Promise（与外部世界交接） | 同步等待 | 11 处 |
| `Effect.runSync(eff)` | 同步执行取结果 | 直接调用 | 8 处（解码等） |
| `Effect.runPromiseWith(context)` | 带环境执行 | — | mcp/oauth.ts |

> **边界原则**：run* 只出现在"效应世界与非效应世界交界"（runtime 层、IPC 层、测试），业务代码内部全用组合。

## 专节：opencode 自建抽象（非 Effect 标准库）

读 core 源码必须认识的两个自建件：

### LayerNode（`packages/util/src/effect/layer-node.ts`，330 行）

类型化依赖图元系统，Effect Layer 之上的一层：

| API | 作用 |
|---|---|
| `Node.makeGlobalNode({ service, layer, deps })` | 进程级单例节点（Worktree/Job/Workspace…） |
| `Node.makeLocationNode({...})` | 每 Location 一份的节点（Config/Tool/Skill…，16+ 处） |
| `LayerNode.compile(root, { replacements, shared })` | 把节点图编译成 Layer |
| `Node.replace(replacement)` | 整节点替换（含依赖）——测试注入用 |
| `Provider.mapLayer(f)` | 装饰实现、保留接线 |
| `LayerNode.unbound(service, tag)` | 未绑定占位节点（location-service-map 用） |

tag 体系在 `app-node.ts`：`location` 依赖 `global`，`global` 无依赖。

### LayerMap（`core/src/location-services.ts:56`）

按 `Location.Ref` 缓存整套 Location 服务，`idleTimeToLive: Duration.infinity`（不过期）。`LocationServiceMap.Service` 是全局访问入口（`static get(ref)` + `Layer.unwrap` 解析）。

## 附：快速判断"这是什么"

```
看到 Effect<A, E, R>        → 一段待执行的计算（值）
看到 yield* X               → 执行它并取值 / 或声明服务依赖（X 是 Service 时）
看到 Effect.fn("名")        → 命名的可追踪函数
看到 Layer.effect(...)      → 服务的构造蓝图
看到 .pipe(Effect.orDie)    → "这里不该错"，错了就 panic
看到 .pipe(Effect.forkScoped) → 并发执行、挂作用域自动清理
看到 Stream.runForEach      → 消费流（多半是 LLM 事件）
看到 Schema.TaggedError     → 类型化错误定义
看到 runPromise/runFork     → 效应世界与非效应世界的边界
```
