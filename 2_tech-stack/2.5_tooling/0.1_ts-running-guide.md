## 一、TypeScript 是什么？

TypeScript 是 JavaScript 的超集，简单说就是 **带类型的 JavaScript**。浏览器和 Node.js 不能直接运行 TS 文件，需要先转换成 JavaScript 才能运行。

## 二、核心概念速览

### 1. 什么是 `package.json`？

项目配置文件，记录项目的名称、版本、依赖包等信息。

```json
{
  "name": "my-ts-project",
  "version": "1.0.0",
  "dependencies": {
    "axios": "^1.6.0"
  },
  "devDependencies": {
    "typescript": "^5.0.0",
    "ts-node": "^10.9.0"
  }
}
```

- `dependencies`：项目运行时需要的依赖
- `devDependencies`：开发时需要的工具（如 TypeScript 编译器）

### 2. 什么是 `node_modules`？

安装依赖后自动生成的文件夹，存放所有下载的第三方包。**不需要手动修改**，通过命令自动管理。

### 3. 什么是 `tsconfig.json`？

TypeScript 的配置文件，告诉编译器如何转换代码。

```json
{
  "compilerOptions": {
    "target": "ES2020",
    "module": "commonjs",
    "moduleResolution": "node",
    "esModuleInterop": true
  }
}
```

| 配置项 | 作用 |
|--------|------|
| `target` | 编译成哪个版本的 JavaScript |
| `module` | 使用哪种模块系统（commonjs / esnext） |
| `moduleResolution` | 如何解析 import 的模块路径 |
| `esModuleInterop` | 兼容 CommonJS 和 ES Module 的导入方式 |

## 三、常用命令详解

### 1. `npm init -y`

初始化项目，自动生成 `package.json` 文件。

```bash
npm init -y
```

### 2. `npm install <包名>`

安装依赖包到 `node_modules` 中。

```bash
# 安装 axios 到 dependencies
npm install axios

# 安装 typescript 到 devDependencies
npm install -D typescript
```

| 参数 | 含义 |
|------|------|
| `-D` 或 `--save-dev` | 安装到 devDependencies |
| `-g` | 全局安装（所有项目可用） |

### 3. `npx ts-node <文件名>`

直接运行 TS 文件，不需要手动编译。

```bash
npx ts-node hello.ts
```

### 4. `npx tsx <文件名>`

另一个 TS 运行工具，速度更快，支持更多特性。

```bash
npx tsx hello.ts
```

### 5. `tsc <文件名>`

TypeScript 编译器，把 TS 文件编译成 JS 文件。

```bash
# 编译 hello.ts 生成 hello.js
tsc hello.ts

# 然后用 Node 运行
node hello.js
```

### 6. `node <文件名>`

运行 JavaScript 文件（Node.js 环境）。

```bash
node hello.js
```

## 四、三种运行方式对比

| 方式 | 命令 | 适用场景 | 优点 | 缺点 |
|------|------|---------|------|------|
| **ts-node** | `npx ts-node file.ts` | 本地开发调试 | 直接运行，无需编译 | 首次运行较慢 |
| **tsx** | `npx tsx file.ts` | 本地开发调试 | 速度快，支持 ESM | 需要额外安装 |
| **tsc + node** | `tsc file.ts && node file.js` | 正式部署 | 生成标准 JS 文件 | 需要两步操作 |

## 五、完整实战流程

### 场景：运行一个带 axios 依赖的 TS 文件

**第一步：创建项目**

```bash
mkdir my-project
cd my-project
npm init -y
```

**第二步：安装依赖**

```bash
# 安装运行时依赖
npm install axios

# 安装开发工具
npm install -D typescript ts-node
```

**第三步：创建 TS 文件**

```typescript
// fetch-data.ts
import axios from 'axios';

async function fetchData() {
  const response = await axios.get('https://api.github.com');
  console.log('请求成功:', response.data);
}

fetchData();
```

**第四步：运行**

```bash
npx ts-node fetch-data.ts
```

## 六、常见问题排查

### 1. 报错 `Cannot find module 'xxx'`

说明依赖没有安装，执行：

```bash
npm install xxx
```

### 2. 报错 `Cannot find module 'typescript'`

说明 TypeScript 没安装：

```bash
npm install -D typescript
```

### 3. 报错 `import` 相关错误

可能是模块配置问题，检查 `tsconfig.json` 中的 `module` 和 `esModuleInterop` 配置。

### 4. 报错 `npx` 找不到命令

说明 Node.js 没安装，先去 https://nodejs.org 下载安装。
