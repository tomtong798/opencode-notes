# CQRS 投影（Projection）

## 是什么

**CQRS（Command Query Responsibility Segregation，命令查询职责分离）**：写入模型与读取模型分开。

- 写侧：命令产生事件（追加日志）
- **投影（projection）**：订阅事件流、按序把事件"折叠"进查询优化的读表
- 读侧：只查读表，永不直接折叠日志

## 业界类比

- 流水（写侧）→ 自动记账到报表（读侧）
- 数据仓库的 ETL 物化视图，但**同库同事务、近实时**

## 在 OpenCode 中的角色

- **`SessionProjector`**（`packages/core/src/session/projector.ts`）为每个 durable Session 事件注册投影器：
  - **与事件发布在同一 SQLite 事务内执行**（这是本仓库投影的关键约束：读模型绝不滞后于事实）
  - 维护读表：`session_v2`（元数据/usage/claim/revert 状态）、`session_message`（消息，seq 排序）、`session_inbox`（未消费工作）、`instruction_entry/state`（指令）
  - 特殊折叠：fork 复制消息历史、revert 删边界后消息、compaction 推进指令 epoch
- 读模型可**富化**：需要自包含视图时（含 previous/derived 状态）在投影时补齐，而不是多记事件（红线：durable 事件保持最小）
- 无效投影以 defect 中止事务（Bus/投影边界协议）

## 与其他技术的关系

- **事件溯源**：投影是事件溯源的"读侧出口"（见 [event-sourcing.md](3_event-sourcing.md)）
- **SSE**：客户端侧 `createData()` 是同一思想在 UI 端的复刻——事件流投影成 store
- **Drizzle**：读表的类型化读写
